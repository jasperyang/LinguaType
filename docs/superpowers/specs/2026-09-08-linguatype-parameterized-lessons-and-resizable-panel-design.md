# LinguaType 参数化学习模板与可调整浮窗设计

## 目标

将现有只支持少量完整示例句的本地课程，扩展为可验证的参数化语言模板；同时让学习浮窗具备可移动、可调整尺寸且可记住用户偏好的桌面行为。

本阶段覆盖现有三种语言：法语、英语、日语。所有课程内容继续本地生成，不向第三方发送用户输入，也不使用生成式模型猜测词组对应。

## 非目标

- 不在本阶段引入联网 AI、完整句子上传或服务端账户。
- 不把分词结果直接当作学习点。
- 不为未通过本地证据验证的句子生成句子映射、解释或练习。
- 不增加系统通知。

## 参数化学习模板

### 模板结构

每种语言的模板由四部分组成：

1. 中文输入结构：受限的词槽，例如“在 + 地点 + 动作”。
2. 本地词表：允许进入每个词槽的地点和动作，以及各语言的可靠对应形式。
3. 目标语言结构：用于验证翻译中确实存在的语法锚点，例如日语“地点で + 动作”。
4. 课程产物：句子映射、学习点、可选解释、微练习和证据标识。

模板匹配需要同时满足中文结构、词表条目和目标译文锚点；缺少其中任一条件即不匹配。

### 第一批模板

首批扩展高频的“地点 + 活动”意图：

- 中文：`在 + 已知地点 + 生活／工作／学习`
- 日语：`地点で + 生活する／働く／勉強する`
- 法语：`vivre／travailler／étudier à + 地点`
- 英语：`live／work／study in + 地点`

地点词表先提供有限、显式的常见城市与地区。每个条目包含中文形式、各目标语言形式、以及稳定的本地标识。动作同样由有限词表定义。模板不得通过模糊匹配或未知词翻译扩展词槽。

### 课程生成

匹配成功时，按用户选定的主语言和级别生成：

- `句子拆解`：仅显示经过同一模板验证的源词组与目标词组。
- `值得记住`：显示目标语言结构、读音、中文意思和一个本地示例。
- `为什么这么说`：仅在模板配置了语言差异解释时显示。
- `试一下`：仅使用该模板明确配置的正确项和干扰项。

初级和中级展示结构和填空；高级可切换为更精炼的表达点。无匹配或当前级别无合格内容时，保留翻译区与词典区，不显示不可靠的深度学习模块。

## 浮窗交互与尺寸模型

### 移动

顶部控制项之间的空白拖动区移动浮窗。语言下拉、模式开关、固定、复制、展开以及练习控件不触发移动。

### 尺寸模式

浮窗维护 `automatic` 与 `userOverride` 两种尺寸来源：

- `automatic`：初始宽度为 520pt，按内容计算高度。
- `userOverride`：用户从任意边缘或角落调整后，保存宽度和高度；新内容优先保持该尺寸。

手动尺寸按用户和显示器可用区域持久化。切换屏幕或恢复时先进行安全裁剪，再使用保存值。

### 边界和溢出

- 最小尺寸保证标题、主译文及至少三行翻译可读。
- 最大尺寸不超过目标屏幕 `visibleFrame` 的安全边距。
- 内容高度未超过当前尺寸时，窗口在自动模式随内容伸缩。
- 用户覆盖或超过安全高度时，固定顶部信息，学习区域在内部 `NSScrollView` 中滚动。

## 视觉系统

保持深蓝灰面板和少边框原则。各学习阶段只使用一个低饱和强调色，并用极低透明度的背景面区分：

| 阶段 | 颜色 |
| --- | --- |
| 原文／主译文 | 理解蓝 |
| 句子拆解／语言说明 | 对照紫 |
| 值得记住 | 琥珀 |
| 微练习 | 薄荷 |
| 加入复习／复习卡 | 玫瑰 |

翻译行之间保持 8pt 间距；复制与展开控制保持紧凑，且不抢正文的阅读权重。

## 模块边界

- `ParameterizedLessonContentPack`：本地词表、模板和候选课程的定义。
- `TemplateLessonMatcher`：在单一可测试边界验证输入、目标译文与词槽。
- `TutorLessonPlanner`：在现有候选课程排序、级别过滤和四项上限之外，接入参数化候选。
- `PanelSizePreferences`：保存用户覆盖尺寸。
- `PanelResizeController`：从窗口边缘／角落手势计算目标尺寸，并执行安全裁剪。
- `TranslationPanel`：协调内容高度、自动尺寸、手动尺寸与跨屏位置。

## 测试与验收

单元测试：

- 三种语言的地点活动模板接受已知地点和动作，拒绝未知词、翻译缺锚点和不匹配结构。
- 每个成功匹配具有非空证据标识；失败输入不生成课程。
- 学习级别继续过滤不适用的候选课程。
- 尺寸裁剪遵守最小值、屏幕安全边距与用户覆盖优先级。

界面回归：

- 三种翻译行保留紧凑复制与展开控件，并有明确行距。
- 面板可从标题栏空白区域拖动；按钮点击保持原有功能。
- 自动、手动和深度溢出三种尺寸状态各自正确显示。

手工验收：

1. 在 TextEdit 输入“在东京生活”“在巴黎工作”“在伦敦学习”等已知词表组合。
2. 切换 FR／EN／JP 主语言和极简／深度模式，验证不同语言结构与相应颜色。
3. 固定面板，拖动顶部空白区；分别拖动右边、下边与右下角调整尺寸。
4. 输入较长句子，确认窗口不越过屏幕，内容在学习区滚动。
5. 对未在词表中的地点或动作确认只显示翻译／词典，不显示虚构拆解。
